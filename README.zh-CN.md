# Ops Tool Spec (OTS)

本规范规定运维类软件向自主调用方暴露的工具、这些工具所返回结果的结构，以及修改系统状态的
工具得以执行的条件。

本规范位于工具传输层（例如 [Model Context Protocol](https://modelcontextprotocol.io)）之上，
不定义传输、发现与调用。

**版本 0.1 — 草案，不稳定。** 在 1.0 之前的任何小版本都可能引入破坏性变更。

## 内容

| 路径 | 内容 |

| `spec/v0.1/core.zh-CN.md` | 中文译本（参考性文本） |
| `schema/` | 机器可读定义 |

规范性文本为英文。译本与英文有出入时，以英文为准。

## 范围

核心规范定义：

- 工具按只读与改动进行声明
- 结果的结构：判定、判定码与错误
- 改动得以执行的条件
- 长时操作的处理
- 符合性类别与版本

本规范不定义任何领域专用工具，该部分由领域规范定义。
